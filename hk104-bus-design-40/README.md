# HK-104 40厘米比例版製作說明

這是原64厘米完整方案另存的40厘米版本，縮放係數40÷64＝0.625。原版保留；本版仍有上層64座、下層40座、獨立司機椅、12級立體樓梯、活動前門、可取車頂及四柱四帶拆合機關。這是原創香港風格展示模型，不代表特定真實巴士。

0.9375是原1.5毫米厚度乘0.625的理論值，不是承諾可買到的標準材料。表內4層地板、2層牆等是這個理論基準；若用0.5、0.75或1毫米材料，必須量壓乾後的完成厚度，搭配薄紙補層或修磨至目標，而不是照原裁片數直接疊。1.875和3.75難以人工精確達到，應以試件確認允許誤差；端牆嵌入、樓梯高度、四柱配合及透明片加厚都要特別試合。

## 製作與驗收

1. 先做1雙人座、1接頭及1紙盒，試紙厚、黏邊和孔徑。
2. 長板紙樣拼好，描裁硬卡，疊合壓平至目標厚度。
3. 下層窗片、牆、承托、補強塊及4棒；核對接合面z81.25。
4. 上層梯孔、三邊U框、4底肋及4套管，試20次拆合。
5. 固定下層樓梯及底L翼；梯頂能自由穿孔，不刮邊。
6. 上層32、下層20雙人模組；數U01–U64、L01–L40，司機另計。
7. 司機台、收費器、輪椅靠板、扶手、箱、上層牆、車頂、輪和門。
8. 黏4鎖帶，乾透後驗收：四角落座、管柱不鬆、不堵通道、樓梯不扯扶手。地板彎曲補肋，不能靠更緊的帶硬拉。

本版未實物試製，數學小數位不代表刀切精度、接頭強度或保證配合。只作桌面展示，不倒轉、不跌落、不載重；刀具需成人協助，木棒磨圓，不用尖籤、釘或小磁石。不抓車頂或上層提整車。
