# HK-104 薄卡坐姿人仔：104個A4橫向列印圖

輸出為一張300dpi PNG列印圖，104個人仔，26個一行、共4行。每個人仔只剪一件8 × 47毫米長方形；手、腳、頭髮只印出，不另外剪。由頭頂起22及38毫米各壓一條摺線，坐姿時上身向上，大腿朝前，小腿向下；不需黏接組成人仔。

[開啟／下載PNG原圖](HK-104_薄卡坐姿人仔_104個_A4橫向_300dpi.png)。請保存原圖再列印，不要列印網頁縮圖或聊天截圖。

## 列印及製作

- **紙張**：A4橫向，使用容易壓摺的薄卡，不用車身的1毫米灰硬卡。
- **比例**：100%實際大小，關閉符合頁面及自動縮放，勿列印聊天截圖。PNG為3508 × 2480像素，帶300dpi資訊；像素取整造成的名義整頁尺寸差少於0.04毫米，但印表機或軟件仍可能改比例。
- **校準**：先量圖上50毫米線；不是50毫米就調整列印設定，不要直接批量剪。必要時在列印軟件把圖像實際寬設為297毫米，保持長闊比例。
- **壓線**：先在每整行的兩條虛線壓摺線，再剪整行及分成26件，最後逐個摺兩下。只剪外框及分件直線，身上圖案不剪。
- **坐好**：以大腿有圖案的一面向上，讓上身向上摺90度、膝部反向向下摺90度，靠椅背，雙腿在座位前緣垂下。先試1個，有膠層或摺彎干涉時先調坐姿，不硬塞。

## 尺寸核對

沿用本專案39.3厘米實作版：單席名義闊13.042857、深15.965625毫米，座面離地9.825毫米。人仔闊8、座面以上22、大腿16、小腿9毫米；名義左右各餘2.5214毫米，小腿底離地0.825毫米。大腿比名義座深多0.034375毫米，讓膝線略在座面前緣以外，腿不穿過座面。

這是簡化長條人仔，不是寫實人體比例。腿部不加向前的腳掌摺片，避免佔上層相鄰排座的空間；未經實物試製，薄卡厚度及膠層可能影響實際配合，需先試件。
