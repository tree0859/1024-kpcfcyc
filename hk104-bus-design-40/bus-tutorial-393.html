01準備與試件

步驟 01 / 42 · B1

確認無柱版本、分袋與材料

B1實測393 × 83毫米，車頭為x0、右側為y0，地面為z0。分袋保留下層、上層、車頂、內裝及試件；不用J3接頭塊、J12木棒或J13套管。 〔尺寸依據〕

完成後檢查：新製作灰卡174片／65完成件，結構內裝663件含可選F11；不用F11為662。不含外皮與人仔，104乘客席不變。

注意：灰卡1毫米整層，地板4、牆及頂2。高度倍率0.9825仍是工作假設，未經實物試製。

步驟 02 / 42 · S1 / S2 / S3 / S4 / F1 / J1 / J7 / J8 / J10 / J11

先試一座、一盒和一角承托

先按21–23做雙人試椅，按25做F1試盒，再用2毫米框試片、4毫米地板試片及一條外側翻帶檢查平放承托。合格試件計入正式數量。 〔尺寸依據〕

完成後檢查：椅高及盒件封合正常；B2試片直接坐框頂，不夾水平魔術貼，外側帶可解開。

注意：不做棒管試件，不鑽定位孔；不先裁完663件才發現摺法不合。

步驟 03 / 42 · B1 / B2 / B10

裁長板並分層壓平

B1與B2每片外框393 × 83，各裁4片疊成4毫米；B10同外框裁2片疊成2毫米。薄塗白膠、對齊四角，夾在平整板之間壓乾；在內面寫編號及前、右方向。 〔尺寸依據〕

完成後檢查：兩塊地板外廓相同，長邊不彎；B1既有合格外框保留。若B1已有別的疊厚，先確認，不直接當4毫米。

注意：舊紙樣頁只參考形狀；不是修改尺寸標籤後沿舊線剪，也不假定每頁列印誤差都相同。

02車身、窗及下層空殼

步驟 04 / 42 · B3 / B4 / B5 / B6 / B7 / B8 / B9 / B11

裁牆板、門片及新窗洞

下層兩側牆各393 × 61.40625、前後端牆各79 × 61.40625；上層側牆各393 × 52.809375、端牆各79 × 52.809375。每件均2層。B11裁23.9484375 × 48.5109375，2層；按修正表重新標窗、門洞。 〔尺寸依據〕

完成後檢查：下層左側門洞x7.37起，24.56 × 49.13，由牆底開口；右側相同前區是司機窗。端窗起點從79毫米端牆邊量。

注意：先在兩片灰卡各開洞，再對齊疊合；透明窗不夾入兩層。B7後格柵只貼面，不挖成大洞。

步驟 05 / 42 · B3 / B4 / B5 / B10 / B11

先描外皮孔位，未裝窗前預裁紙

把每塊新牆板及門片放在薄紙背面描外框、窗洞和門洞，寫清左右及上下層。卡其紙或舊彩印外皮先用描紙試對；預裁洞口，暫不整車包貼。 〔尺寸依據〕

完成後檢查：四塊側面、四個端面、車頂及門分開處理；車身接合縫、車頂縫和門縫都有獨立紙邊。

注意：舊40厘米彩印外皮不能只剪短便假定窗位對準。刀不可隔著外皮在已貼好的透明窗上切割。

步驟 06 / 42 · G1 / G2 / G3 / G4 / G5 / G6 / G7 / G8 / G9 / G10

把57片透明窗貼在牆內面

G1–G10按新尺寸共裁57片透明片，只裁外輪廓，不挖掉中間透明部分。薄膠只塗窗洞周邊的黏邊，貼在已完成2層牆的內面；上層窗牆及G10門窗先備好。 〔尺寸依據〕

完成後檢查：由外側看窗洞清楚，膠不遮視線；窗片與邊緣留出車牆對接及承托位置。片尺寸已含黏邊，不再統一加5毫米。

注意：不能沿用歷史『把窗片夾在兩層灰卡之間』的做法；不把額外膠片厚度當作1毫米灰卡層。

步驟 07 / 42 · B1 / B3 / B4 / B6 / B7

在B1頂上組下層空殼

四牆都放在B1頂面，不貼到地板外邊。B3、B4側牆沿長邊，B6、B7端牆夾在兩側2毫米牆之間。先用方尺乾合，再分邊上膠固定，保持內部可從上面操作。 〔尺寸依據〕

完成後檢查：外廓仍393 × 83，內腔389 × 79；下層牆由地面z19起，牆頂z80.40625。

注意：不要把端牆再加在側牆外端而令車長增加；保持門片可開及前門洞無膠堆。

03無孔承托框與平整檢查

步驟 08 / 42 · J7 / J8

製作並定位12個托座

側面J7裁10片12.28 × 17.28，端面2片11.86 × 17.28；長向距12.28摺，餘5作水平翼。每座配2片J8，直角邊12.28 × 5、單層1毫米。托翼頂對齊框底z78.40625。 〔尺寸依據〕

完成後檢查：左右各5、前後各1；翼向車內，貼牆面向下。原建議中心遇門窗洞時須調到完整牆面，先乾放標記，不盲貼。

注意：J8在托翼下，不能疊到框頂；完整定位和示意見無柱17步專篇。

步驟 09 / 42 · J1 / J2

疊好J1／J2承托框

J1兩條各389 × 5 × 厚2；J2兩條各69 × 5 × 厚2。J2夾在J1兩端，不疊角。裝到托座上，J1在y2–7及76–81，四邊都內縮車身外緣2。 〔尺寸依據〕

完成後檢查：框外廓389 × 79、內空379 × 69；框頂和牆頂同高z80.40625，四角平整。

注意：整個框只需8片灰卡，不開棒孔；框與牆頂承托上層，不能隨四柱一起刪掉。

步驟 10 / 42 · J1 / J2 / J7 / J8

檢查承托框頂水平

不再做J3接頭塊。核對四邊框及牆頂均在z80.40625；等薄膠乾透，再以直尺查平整。 〔尺寸依據〕

完成後檢查：框底z78.40625、框厚2；J7/J8托座不插入框的同一體積，四角不疊厚。

注意：不要用厚膠或海綿膠墊高。J3若已黏而棒未黏，可以留塊不用，不強撬框。

步驟 11 / 42 · J1 / J2

略過木棒，檢查無孔承托面

取消四根定位棒，不鑽J1棒孔。已開孔而未黏柱管，可留孔試合，檢查孔邊無裂、起層或明顯變軟。 〔尺寸依據〕

完成後檢查：承托面無凸膠或鬆層；不用另外加一層卡遮孔而改層高。

注意：如果木棒已黏牢，先停下確認實況，不可硬拔、撬框或強壓上層。

步驟 15 / 42 · B2 / J4 / J5 / J6 / J9

取消四段定位套管。B2底只保留U框、四根豎肋及角撐；接觸框頂的位置不墊紙或魔術貼。 〔尺寸依據〕

步驟 16 / 42 · B2 / J1 / J2

注意：不用四孔同時對準，但不是任意偏放或自動定位；有卡住先提起，不能用鎖帶拉平。
