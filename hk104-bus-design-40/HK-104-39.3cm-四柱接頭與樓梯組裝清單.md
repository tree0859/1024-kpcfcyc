# HK-104 39.3厘米實作版：無柱承托與樓梯組裝清單

現行無柱版：原承托框平放＋四條外側魔術貼翻帶。取消J3、定位木棒及套管；不開J1棒孔或B2四管孔，保留梯孔、U框及豎肋。基準393 × 83毫米、1毫米灰卡整層；高度倍率0.9825仍是工作假設，未實物試製，先乾合。

本頁50項只教承托、拆合及樓梯，不是全車完整清單。座椅、門及設施見[全車42步無柱教程](bus-tutorial-393.html)，放大圖見[無柱17步專篇](frame-tutorial-393.html)。原裁切紙樣及PDF不改；手工略過取消件與定位孔。

## 無柱平放與外側翻帶

- [ ] 四條翻帶全部打開，再把上層拿到下層上方。

- [ ] 垂直放下，B2自然坐框及牆頂，不靠樓梯或扶手承重。
- [ ] 原底肋兩側名義間隙約0.6毫米，不能任意偏放。
- [ ] 四角輕按不明顯搖晃；若卡住先提起查凸膠、U框或底肋。
- [ ] 水平承托面直接接觸，不夾魔術貼或海綿膠。

- [ ] 先自然落座，再輕扣一組對角帶，然後扣其餘兩帶。

## 驗收與收納

- [ ] 點數：4翻帶、4對魔術貼、12級梯、2側板、1風琴條、4片T8及19段梯扶手，無定位棒管。
- [ ] 框、U框、底肋、門及座椅無碰撞；不靠膠堆填或拉帶掩蓋不合。
- [ ] 帶梯、完整側牆及104席試拆，樓梯與扶手沒有跨層黏死。
- [ ] 框牆無裂或鬆，翻帶黏底不翹起；有異常先停下修正。
- [ ] 分層前鬆四帶、提至少12毫米，再以至少12毫米高邊墊保存，避開底肋。
- [ ] 上層64席、下層40席、司機另計；搬整車托下層底板，不抓上層或車頂。

未經實物試製或強度認證。12毫米是名義最低提起及邊墊高度，膠層或檯面誤差大時，另用更高整毫米墊塊。
